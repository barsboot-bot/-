# 📼 Как создать новую кассету / диск для мода MusicRadio

**Правило: 1 кассета (или 1 диск) = 1 PBO-аддон.**

Каждый носитель — это отдельный аддон `MusicRadio_Tape_<Имя>.pbo` /
`MusicRadio_Disc_<Имя>.pbo`, который:

* объявляет класс предмета, наследующий базовый (`MR_Item_Cassette_Rock` / `MR_Item_Disk_Classic`) из `MusicRadioCore`;
* содержит встроенный звук `sound/*.ogg` (играет через штатный SoundSource движка);
* привязан к плейлисту внешней библиотеки сервера `Music/Type/<Имя>/` (кассеты) или `Music/CD/<Имя>/` (диски).

---

## Способ A — автоматический (рекомендуется)

```bash
python3 tools/new_cassette.py \
    --type tape \
    --name "Ночной Рок" \
    --class NightRock \
    --music-dir "/путь/к/трекам"
```

Что получится:

```
@MusicRadioCore/Addons/MusicRadio_Tape_NightRock/
├── config.cpp            # CfgPatches + CfgVehicles(MR_Item_Cassette_NightRock) + CfgSounds
└── sound/
    ├── track1.ogg        # скопированы из --music-dir (или заглушка sample.ogg)
    └── ...
@MusicRadioServer/Music/Type/NightRock/meta.txt   # name = Ночной Рок
build/out/@MusicRadioCore/Addons/MusicRadio_Tape_NightRock.pbo
```

Флаги: `--type tape|disk`, `--name` (отображаемое имя), `--class` (латиницей, без пробелов),
`--music-dir` (папка с .ogg/.mp3/.wav), `--out` (куда положить PBO).

## Способ B — вручную (по гайдлайну BI «Creating a mod»)

### 1. Каркас аддона

```
MusicRadio_Tape_MyMix/
├── config.cpp
└── sound/
    └── mytrack.ogg        # OGG Vorbis ≤ 48 kHz (формат BI)
```

### 2. `config.cpp`

```cpp
class CfgPatches
{
    class MusicRadio_Tape_MyMix
    {
        name = "Моя Кассета";
        author = "KRa Tos (Konstantin)";
        version = "1.1.0";
        requiredVersion = 0.1;
        requiredAddons[] = {"DZ_Data", "DZ_Scripts", "MusicRadioCore", "MusicRadioServerInit"};
        units[] = {"MR_Item_Cassette_MyMix"};
        weapons[] = {};
    };
};

class CfgVehicles
{
    class MR_Item_Cassette_Rock;          // базовый класс из MusicRadioCore

    class MR_Item_Cassette_MyMix: MR_Item_Cassette_Rock
    {
        scope = 2;
        displayName = "Кассета: Моя Кассета";
        uePlaylist = "MyMix";             // папка Music/Type/MyMix на сервере
    };
};

class CfgSounds
{
    sounds[] = {};
    class MR_Item_Cassette_MyMix_Sound
    {
        name = "MR_Item_Cassette_MyMix_Sound";
        sound[] = {"sound\mytrack.ogg", 0, 1};
        distance[] = {0, 150, 160};       // затухание до 150 м
    };
};
```

Для диска: наследуйтесь от `MR_Item_Disk_Classic`, префикс класса —
`MR_Item_Disk_`, библиотека — `Music/CD/`.

### 3. Упаковка в PBO

**Официальный путь (DayZ Tools):**
1. Steam → DayZ Tools → **Addon Builder**;
2. Sources: `@MusicRadioCore/Addons`, Keys: ваш `.biprivatekey`;
3. Build → `MusicRadio_Tape_MyMix.pbo` (подписанный);
4. Положите PBO в `@MusicRadioCore/Addons/` клиента и сервера.

**Fallback (тесты, без подписи):**
```bash
python3 tools/pack_pbo.py build/staging build/out/@MusicRadioCore/Addons
```

### 4. Треки во внешней библиотеке сервера

```
<Profile>/Music/Type/MyMix/
├── meta.txt          # name = Моя Кассета
├── track1.ogg
└── track2.mp3
```

Сервер сканирует `Music/` при старте и рассылает клиентам манифест;
клиенты докачивают треки по `MR_Config::libraryBaseURL`
(`tools/serve_music.py` поднимает HTTP-зеркало). Пересборка PBO **не нужна**.

### 5. Раздача предмета в игре

Добавьте класс в спавн-таблицу сервера:

```ini
[ueItemCassetteMyMix]
name=MR_Item_Cassette_MyMix
min=1 max=1 qty=1 chance=0.02 percent=
```

## 🎨 Обложка новой кассеты / диска

Класс предмета готов — теперь у него должна быть своя этикетка. Исходники
текстур рисуются скриптом (никаких скачанных картинок, лицензия чистая):

1. Добавьте альбом в список `ALBUMS` в `tools/make_textures.py`
   (`id` = имя папки плейлиста, `title`, `sub`, `color`, `minutes`)
   и в кортеж `ALBUMS` в `tools/make_rvmat.py`.
2. Перегенерируйте:

   ```bash
   python3 tools/make_textures.py --albums     # только обложки
   python3 tools/make_rvmat.py                 # материалы под новые обложки
   python3 tools/render_preview.py --album <id>   # посмотреть глазами
   ```

3. Сконвертируйте новые PNG в `.paa` через TexView 2 и пропишите классу
   `hiddenSelectionsMaterials[]` на свой `.rvmat`.

Подробно — `docs/17_ASSETS.md`, раздел 5.

## Чек-лист новой кассеты

- [ ] Класс наследуется от `MR_Item_Cassette_Rock` / `MR_Item_Disk_Classic`
- [ ] `requiredAddons[]` включает `MusicRadioCore` **и** `MusicRadioServerInit`
- [ ] Аудио в OGG Vorbis, путь в `CfgSounds` относительный внутри PBO
- [ ] `uePlaylist` = имя папки в `Music/Type|CD`
- [ ] PBO подписан Addon Builder'ом (для продакшена)
- [ ] `meta.txt` положен в библиотеку сервера
- [ ] Тест: предмет заспавнен → вставлен в плеер → играет всем рядом
