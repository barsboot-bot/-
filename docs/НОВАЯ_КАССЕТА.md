# 📼 Как создать новую кассету / диск для мода «унесённые»

**Правило: 1 кассета (или 1 диск) = 1 PBO-аддон.**

Каждый носитель — это отдельный аддон `Uness_Tape_<Имя>.pbo` /
`Uness_Disc_<Имя>.pbo`, который:

* объявляет класс предмета, наследующий базовый (`UE_Item_Cassette_Rock` / `UE_Item_Disk_Classic`) из `Uness_Data`;
* содержит встроенный звук `sound/*.ogg` (играет через штатный SoundSource движка);
* привязан к плейлисту внешней библиотеки сервера `Music/Type/<Имя>/` (кассеты) или `Music/CD/<Имя>/` (диски).

---

## Способ A — автоматический (рекомендуется)

```bash
python3 tools/new_cassette.py \
    --type tape \
    --name "Ночной Рок" \
    --class NightRock \
    --music-dir "/путь/к/трекам"
```

Что получится:

```
@Uness/Addons/Uness_Tape_NightRock/
├── config.cpp            # CfgPatches + CfgVehicles(UE_Item_Cassette_NightRock) + CfgSounds
└── sound/
    ├── track1.ogg        # скопированы из --music-dir (или заглушка sample.ogg)
    └── ...
@KRa_TosServer/Music/Type/NightRock/meta.txt   # name = Ночной Рок
build/out/@Uness/Addons/Uness_Tape_NightRock.pbo
```

Флаги: `--type tape|disk`, `--name` (отображаемое имя), `--class` (латиницей, без пробелов),
`--music-dir` (папка с .ogg/.mp3/.wav), `--out` (куда положить PBO).

## Способ B — вручную (по гайдлайну BI «Creating a mod»)

### 1. Каркас аддона

```
Uness_Tape_MyMix/
├── config.cpp
└── sound/
    └── mytrack.ogg        # OGG Vorbis ≤ 48 kHz (формат BI)
```

### 2. `config.cpp`

```cpp
class CfgPatches
{
    class Uness_Tape_MyMix
    {
        name = "Моя Кассета";
        author = "KRa Tos (Konstantin)";
        version = "1.0.0";
        requiredVersion = 0.1;
        requiredAddons[] = {"DZ_Data", "DZ_Scripts", "Uness_Data", "KRa_TosServerInit"};
        units[] = {"UE_Item_Cassette_MyMix"};
        weapons[] = {};
    };
};

class CfgVehicles
{
    class UE_Item_Cassette_Rock;          // базовый класс из Uness_Data

    class UE_Item_Cassette_MyMix: UE_Item_Cassette_Rock
    {
        scope = 2;
        displayName = "Кассета: Моя Кассета";
        uePlaylist = "MyMix";             // папка Music/Type/MyMix на сервере
    };
};

class CfgSounds
{
    sounds[] = {};
    class UE_Item_Cassette_MyMix_Sound
    {
        name = "UE_Item_Cassette_MyMix_Sound";
        sound[] = {"sound\mytrack.ogg", 0, 1};
        distance[] = {0, 150, 160};       // затухание до 150 м
    };
};
```

Для диска: наследуйтесь от `UE_Item_Disk_Classic`, префикс класса —
`UE_Item_Disk_`, библиотека — `Music/CD/`.

### 3. Упаковка в PBO

**Официальный путь (DayZ Tools):**
1. Steam → DayZ Tools → **Addon Builder**;
2. Sources: `@Uness/Addons`, Keys: ваш `.biprivatekey`;
3. Build → `Uness_Tape_MyMix.pbo` (подписанный);
4. Положите PBO в `@Uness/Addons/` клиента и сервера.

**Fallback (тесты, без подписи):**
```bash
python3 tools/pack_pbo.py build/staging build/out/@Uness/Addons
```

### 4. Треки во внешней библиотеке сервера

```
<Profile>/Music/Type/MyMix/
├── meta.txt          # name = Моя Кассета
├── track1.ogg
└── track2.mp3
```

Сервер сканирует `Music/` при старте и рассылает клиентам манифест;
клиенты докачивают треки по `UE_Config::libraryBaseURL`
(`tools/serve_music.py` поднимает HTTP-зеркало). Пересборка PBO **не нужна**.

### 5. Раздача предмета в игре

Добавьте класс в спавн-таблицу сервера:

```ini
[ueItemCassetteMyMix]
name=UE_Item_Cassette_MyMix
min=1 max=1 qty=1 chance=0.02 percent=
```

---

## Чек-лист новой кассеты

- [ ] Класс наследуется от `UE_Item_Cassette_Rock` / `UE_Item_Disk_Classic`
- [ ] `requiredAddons[]` включает `Uness_Data` **и** `KRa_TosServerInit`
- [ ] Аудио в OGG Vorbis, путь в `CfgSounds` относительный внутри PBO
- [ ] `uePlaylist` = имя папки в `Music/Type|CD`
- [ ] PBO подписан Addon Builder'ом (для продакшена)
- [ ] `meta.txt` положен в библиотеку сервера
- [ ] Тест: предмет заспавнен → вставлен в плеер → играет всем рядом
