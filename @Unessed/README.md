# 📼 Унесённые | Unessed

**Версия:** 1.0.0
**Игра:** DayZ Standalone
**Автор:** KRa Tos (Константин)
**Лицензия:** Только для использования на сервере «Унесённые»

Атмосферный мод, добавляющий прослушивание музыки: аудиокассеты, виниловые диски, серверное радио и автомагнитолы с реалистичным 3D-затуханием звука.

⚠️ Мод содержит проверку целостности: без `Unessed_Server.pbo` на сервере запуск приведёт к аварийной остановке (CRASH). Это преднамеренная защита.

## Структура
```
@Unessed/
├── Addons/
│   ├── Unessed_Core.pbo      # Основные скрипты
│   ├── Unessed_Sounds.pbo    # Звуковые файлы
│   ├── Unessed_Items.pbo     # Предметы (кассеты, диски)
│   └── Unessed_Server.pbo    # Серверная часть (ОБЯЗАТЕЛЬНО)
├── Keys/
│   └── unessed.bikey         # Публичный ключ
└── README.md
```
